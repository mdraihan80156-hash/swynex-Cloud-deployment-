Basic Cloud Deployment – SWYNEX Internship Task 2

Project Overview

This project demonstrates the deployment of a simple Cloud Computing Portfolio website using GitHub Pages.

Objective

To create a static website and make it publicly accessible through a cloud-based hosting platform.

Technologies Used

- HTML
- CSS
- GitHub
- GitHub Pages

Website Features

- Home section
- About Cloud Computing
- Cloud Computing Services
- Learning Skills
- Contact section
- Responsive design

Deployment Procedure

1. Created a public GitHub repository.
2. Created the index.html file.
3. Added HTML and CSS code.
4. Uploaded the website to GitHub.
5. Opened repository Settings.
6. Selected GitHub Pages.
7. Configured deployment using the main branch and root folder.
8. Enabled GitHub Pages hosting.
9. Verified that the website was accessible online.
